# منصة القائد التعليمية

موقع عربي متجاوب لمنصة التاريخ مع الأستاذ زاهر جمال. يحتوي على أقسام أولى ثانوي، تانية بكالوريا، وتالتة ثانوي، وبطاقات المحاضرات الأولى بالنص «اصبر لسا هتنزل».

## تشغيل الموقع محليًا
افتح `index.html` في المتصفح. لا يحتاج المشروع إلى تثبيت حزم أو تشغيل خادم.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع الملفات الموجودة داخل هذا المجلد إلى جذر المستودع، وليس ملف ZIP نفسه.
3. افتح **Settings → Pages**.
4. في **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages.

## مهم بخصوص الحسابات ورفع الفيديوهات
هذه النسخة جاهزة كواجهة موقع ثابتة، لكنها لا تحتوي على خادم أو قاعدة بيانات مشتركة. تسجيل الحسابات التجريبي يُحفظ في `localStorage` على نفس المتصفح والجهاز فقط، وكلمات المرور في هذا النموذج ليست مشفّرة؛ لذلك لا تستخدمه لحسابات حقيقية أو بيانات حساسة.

صلاحيات المدير ورفع الفيديوهات لا يمكن تأمينها داخل ملفات HTML/JavaScript وحدها؛ لأن أي زائر يستطيع فحص كود الموقع. لإطلاق المنصة فعليًا مع حسابات طلاب وقاعدة بيانات ورفع فيديوهات للمدير فقط، اربط الواجهة بخدمة خلفية مثل Firebase أو Supabase مع قواعد صلاحيات صحيحة وتخزين ملفات. روابط الفيديو الخارجية يمكن إضافتها بعد تجهيز خدمة الإدارة الآمنة.

## الملفات
- `index.html` — هيكل الموقع ومحتواه.
- `style.css` — التصميم المتجاوب.
- `script.js` — التفاعلات والأقسام ونموذج الحساب التجريبي.
